# AI Text Summarization Tool using NLP
An AI-powered Text Summarization Tool developed using Python, NLP, Sumy, and NLTK that generates concise summaries from lengthy articles through an interactive GUI interface.


## Overview
The AI Text Summarization Tool is a Python-based application developed using Natural Language Processing (NLP) techniques. This project summarizes lengthy articles or paragraphs into concise and meaningful summaries through a user-friendly graphical interface.

The application uses the LSA (Latent Semantic Analysis) algorithm from the Sumy library along with NLTK for text processing and tokenization.

This project was developed as part of an Artificial Intelligence Internship Task.
